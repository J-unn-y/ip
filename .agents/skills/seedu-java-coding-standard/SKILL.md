# SE-EDU Java Coding Standard

Apply the basic and intermediate rules from the
[SE-EDU Java coding standard](https://se-education.org/guides/conventions/java/intermediate.html) to every Java
file created, modified, or reviewed in this project.

Before working on Java code, read [references/rules.md](references/rules.md) completely. Treat those rules as
mandatory. For topics they do not cover, follow the
[Google Java Style Guide](https://google.github.io/styleguide/javaguide.html), as directed by SE-EDU.

When changing existing code:

1. Keep all new and edited code compliant.
2. Correct nearby violations when doing so is safe and relevant to the requested change.
3. When asked for a project-wide compliance update, audit every Java source and test file.
4. Preserve behavior unless the task explicitly requires a behavior change.
5. Compile and run relevant tests after formatting or structural changes.

In the final response, mention any significant compliance-driven structural change, such as adding packages or
renaming identifiers.
